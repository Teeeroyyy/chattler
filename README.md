# Chattler

A fast, modern Twitch chat client for Windows.

**[Download the latest version](https://github.com/Teeeroyyy/chattler/releases/latest)** — run the installer, then find **Chattler** in your Start Menu. It updates itself automatically.

## Features
- Tabs and resizable splits, drag to reorder
- 7TV, BetterTTV and FrankerFaceZ emotes (each can be turned off)
- One-click **Log in with Twitch**
- Moderation tools: one-click timeouts/bans with undo, chat modes, pinnable user cards,
  **Staff history** (who did what, and when), **Monitor user** colouring
- Highlights with sound, taskbar flash and desktop notifications
- Background transparency and a pin that keeps the window in place and on top

## Notes
- Windows may show "Windows protected your PC" the first time you run the installer
  (it isn't code-signed). Click **More info → Run anyway**.
- This repository only hosts the downloads; the source code is private.
